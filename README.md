# Carousel_JS_Vanilla
Vanilla JS for carousel using DOM for a website

Projet – Refonte d’un site de boulangerie

HTML – CSS – JavaScript (DOM uniquement)

Objectif
Vous recevez une template graphique existante de site de boulangerie. Votre mission est de :
Refaire entièrement le site en HTML, CSS et JavaScript, en vous inspirant uniquement du rendu visuel de la template fournie, sans utiliser aucune librairie JavaScript ni CSS.
Tout le comportement dynamique (carrousel, animations, interactions...) doit être réalisé en JavaScript natif avec le DOM uniquement.

Contraintes obligatoires
Vous devez respecter les règles suivantes :
   • Interdiction d’utiliser : 
       o Bootstrap
       o OwlCarousel 
       o Animate.css 
       o WOW.js
       o jQuery
       o toute autre librairie ou plugin 


Travail attendu

Vous devez :
  • reconstruire toute la structure HTML
  • recréer le style en CSS
  • développer toutes les interactions en JavaScript

Fonctionnalités obligatoires en JavaScript (DOM) 1. Carrousel principal (page d’accueil)

Vous devez créer un carrousel :
  • avec plusieurs slides
  • avec boutons précédent / suivant
  • avec défilement automatique
  • avec arrêt du défilement au survol

Le carrousel doit être codé entièrement par vous.
Carrousel témoignages

Un second carrousel doit être réalisé pour la section témoignages :
  • affichage d’un témoignage à la fois
  • navigation manuelle
  • animation de transition entre les témoignages

Fonctionnalités supplémentaires obligatoires
Vous devez également ajouter :

Un bouton "Retour en haut de page"
  • affiché uniquement après un certain scroll
  • avec animation de remontée

Point très important
Le but de ce projet n’est pas de recopier une template existante. 

Le but est de:
apprendre à recréer un site dynamique
comprendre la manipulation du DOM
comprendre la logique des carrousels et animations
